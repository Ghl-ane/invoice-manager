# InvoiceX — Invoice Management System

A full-stack invoice management application built with **Laravel 12**. Features a clean web UI for day-to-day use and a complete versioned REST API for integrations — both secured with per-user authorization.

> **Live demo:** [invoicex.up.railway.app](https://your-app.railway.app) ← update after deploy  
> **Demo login:** `demo@invoicex.app` / `password`

---

## Features

### Web Application
| Feature | Details |
|---|---|
| Authentication | Register, login, email verification, password reset |
| Client management | Full CRUD, search, per-client invoice count |
| Invoice management | Line items, auto-numbering (INV-001…), status lifecycle, date + search filters |
| Multi-currency | 11 currencies — live rates via FreeCurrencyAPI, 1-hour cache, static fallback |
| Email delivery | Send invoice PDF to client in one click — queued job, PDF auto-attached |
| Public share link | 7-day signed URL — client views invoice without an account |
| PDF export | Branded A4 PDF download via DomPDF |
| Dashboard | Revenue stats, pending amounts, 6-month revenue bar chart |
| Auto-overdue | Scheduled command marks past-due sent invoices as overdue nightly |

### REST API (v1)
| Feature | Details |
|---|---|
| Authentication | Sanctum personal access tokens (`Bearer {token}`) |
| Resources | Full CRUD — clients, invoices, dashboard stats, currencies |
| Authorization | Policy-based — users can only access their own data |
| Responses | Consistent `{"data": ...}` via Laravel API Resources |
| Currency | `GET /api/v1/currencies/convert?amount=&from=&to=` live conversion |

## Installation

```bash
git clone https://github.com/Ghl-ane/invoice-manager.git
cd invoice-manager

composer install
npm install && npm run build

cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan db:seed          # creates demo@invoicex.app / password

php artisan serve
```

**Queue worker** (required for email sending):
```bash
php artisan queue:work
```

**Scheduler** (required for auto-overdue):
```bash
# Add to crontab — or use Railway's cron service
* * * * * cd /path-to-app && php artisan schedule:run >> /dev/null 2>&1
```

**Optional — live currency rates:**
```env
CURRENCY_API_KEY=your_key_from_freecurrencyapi.com
```

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `APP_KEY` | Yes | Generated by `php artisan key:generate` |
| `DB_*` | Yes | MySQL connection details |
| `MAIL_MAILER` | For email | `resend` (production) or `log` (default — logs only) |
| `RESEND_API_KEY` | For email | API key from [resend.com](https://resend.com) |
| `MAIL_FROM_ADDRESS` | For email | Verified sender address in Resend |
| `QUEUE_CONNECTION` | For async email | `database` (runs jobs in background) |
| `CURRENCY_API_KEY` | No | FreeCurrencyAPI key — falls back to static rates |

See `.env.example` for full documentation.

## REST API Reference

Base URL: `/api/v1` — authenticated routes require `Authorization: Bearer {token}`

### Authentication

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | — | Register, returns token |
| POST | `/auth/login` | — | Login, returns token |
| POST | `/auth/logout` | ✓ | Revoke current token |
| GET | `/auth/me` | ✓ | Authenticated user profile |

```http
POST /api/v1/auth/login
Content-Type: application/json

{ "email": "demo@invoicex.app", "password": "password" }
```
```json
{
  "user": { "id": 1, "name": "Alex Morgan", "email": "demo@invoicex.app" },
  "token": "1|abc123..."
}
```

### Clients

| Method | Endpoint | Description |
|---|---|---|
| GET | `/clients` | List (paginated, `?search=`) |
| POST | `/clients` | Create |
| GET | `/clients/{id}` | Show |
| PUT | `/clients/{id}` | Update |
| DELETE | `/clients/{id}` | Delete |

### Invoices

| Method | Endpoint | Description |
|---|---|---|
| GET | `/invoices` | List (paginated, `?search=&status=&from=&to=`) |
| POST | `/invoices` | Create with line items |
| GET | `/invoices/{id}` | Show with items and client |
| PUT | `/invoices/{id}` | Update (status, items, currency…) |
| DELETE | `/invoices/{id}` | Delete |
| GET | `/invoices/{id}/pdf` | Download PDF |

**Statuses:** `draft` → `sent` → `paid` / `overdue`

```http
POST /api/v1/invoices
Authorization: Bearer {token}
Content-Type: application/json

{
  "client_id": 1,
  "issue_date": "2026-06-01",
  "due_date": "2026-06-30",
  "currency": "EUR",
  "notes": "Net 30.",
  "items": [
    { "description": "Web Development", "quantity": 10, "unit_price": 150.00 },
    { "description": "Hosting (1yr)",   "quantity": 1,  "unit_price": 120.00 }
  ]
}
```
```json
{
  "data": {
    "id": 1,
    "invoice_number": "INV-001",
    "status": "draft",
    "currency": "EUR",
    "total": 1620,
    "client": { "id": 1, "name": "Acme Corporation" },
    "items": [
      { "description": "Web Development", "quantity": 10, "unit_price": 150, "subtotal": 1500 },
      { "description": "Hosting (1yr)",   "quantity": 1,  "unit_price": 120, "subtotal": 120 }
    ]
  }
}
```

### Currencies
